GR Note 는 여타의 GR시리즈들과 같이

FTP프로그램을 통한 쉬운 업데이트를 제공합니다.

FTP프로그램을 통해 받으신 파일들을 그대로

덮어씌우신 후, 아래에 안내되는 것처럼

파일들의 퍼미션을 변경해 주시고 사용하시면 됩니다.



※ 업데이트 후 서버에서 퍼미션(권한)을 변경해야 하는 것

- grnote.config.php : 707 로 변경 (644 혹은 755로 되어 있음)



퍼미션을 조절하는 방법은 FTP 프로그램상에서

특정 파일을 오른쪽 클릭하여 나오는 메뉴 중

"권한 설정" 등의 메뉴를 클릭하시면 나타납니다. (프로그램마다 다소 상이함)



※ DB 업데이트가 필요할 경우

업데이트된 GR Note 버젼들 대부분은 매 업데이트 시

DB 부분의 변경이 이루어집니다.

┏━━━━━━━━━━━━━━━━━━━━┓
┃http://여러분의홈페이지/grnote/update/  ┃
┗━━━━━━━━━━━━━━━━━━━━┛

를 브라우저 주소창에 입력한 후(당연히 "여러분의홈페이지" 에는

실제 여러분들의 웹사이트 주소가 들어가야 합니다. ^^

또한 grnote 가 아닌 note, grn 등의 이름으로 업로드 하셨던 분들은

당연히 /grnote/update/ 가 아니라 /note/update/, /grn/update/ 가

되어야 합니다.) 업데이트 완료 페이지를 보시고 난 이후에

GR Note 를 사용해 주시면 되겠습니다.



이 DB업데이트 방법은 GR시리즈들(게시판,블로그,카운터 ...)에

적용되는 공통된 DB업데이트 방법 입니다.
